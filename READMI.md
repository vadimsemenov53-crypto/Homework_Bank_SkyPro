#  🏦 Виджет банковских операций клиента

## Простой виджет на Python для обработки и отображения данных о банковских операциях.

#  🚀 Основные функции:
## 1. Маскировка платёжных данных
### - маскировка номера банковской карты;
### - маскировка номера счёта;
### - автоматическое определение типа данных (карта / счёт).
## 2. Работа с датами:
### - преобразование даты из ISO-формата в читаемый вид (DD.MM.YYYY);
### - обработка некорректных и пустых значений.
## 3. Обработка транзакций:
### - фильтрация операций по статусу (EXECUTED, CANCELED);
### - сортировка операций по дате (по возрастанию и убыванию).
## 4. Генераторы
### - фильтрация транзакций по валюте;
### - поочерёдное получение описаний операций;
### - генерация номеров банковских карт в заданном диапазоне.
## 5. Декоратор
### - отслеживание вызова функций;
### - обрабатывать ошибки;
### - возможность записи в файл;
## 6. Работа с JSON-файлами;
## 7. Конвертирование через API (Exchange Rates Data API);
## 8. В проекте настроено логирование для модулей masks и utils.
## 9. Работа с файлами CSV и Excel
## 10. Функция main предоставляет пользовательский интерфейс в соответствии с условиями задания.

#  🧩 Использование:
### - безопасного отображения платёжных реквизитов;
### - форматирования дат;
### - фильтрации списка операций по статусу и валюте;
### - упорядочивания операций по дате;
### - получение описания операций;
### - логировать вызовы функций и ошибки;
### - выводит данные в консоль или файл;
### - чтение JSON-файлов с банковскими транзакциями;
### - принимать транзакции в валюте и перевод в РУБ;
### - возможность отслеживания поведения программы по логам.
### - возможность считывания финансовых операций из CSV и Excel

## 📦 Установка и запуск

Для работы проекта требуется Python **3.14+** и Poetry.

### 1. Установите Poetry (если ещё не установлен)
```pip install poetry```
### 2. Клонирование репозитория
### `git clone git@github.com:vadimsemenov53-crypto/Homework_Bank_SkyPro.git`
### 3. Установка зависимостей
### ```poetry install```
### 4. Запуск программы
### ```python3 main.py```
### 5. Запуск тестов
### ```pytest```
#### Проверка покрытия кода:
```pytest --cov --cov-report=term-missing```

# 🧪 Тестирование
### Проект содержит полный набор unit-тестов на Pytest, покрывающих:

- корректность маскировки карт и счетов
- обработку дат
- фильтрацию по статусу, валюте
- сортировку по дате
- edge-кейсы (некорректные данные, пустые входные списки и т.п.)
- корректное завершение генераторов (StopIteration).
- корректность логирования аргументов и результата функции 
- логирование ошибок и проброса исключений 
- проверка записи в файл и вывода в консоль 
- проверка обработки некорректного filename
- проверка, обработка пустых и некорректных файлов JSON
- обработка API-статус кодов и отсутствие ключей
- csv/excel - Пустой файл → возвращается пустой список
- csv/excel - Файл не найден → возвращается пустой список
- csv/excel - Некорректный формат данных → возвращается пустой список
