#  🏦 Виджет банковских операций клиента

## Простой виджет на Python для обработки и отображения данных о банковских операциях.

#  🚀 Основные функции:
## 1. Маскировка платёжных данных
### - маскировка номера банковской карты;
### - маскировка номера счёта;
### - автоматическое определение типа данных (карта / счёт).
## 2. Работа с датами:
### - преобразование даты из ISO-формата в читаемый вид (DD.MM.YYYY);
### - обработка некорректных и пустых значений.
## 3. Обработка транзакций:
### - фильтрация операций по статусу (EXECUTED, CANCELED);
### - сортировка операций по дате (по возрастанию и убыванию).
## 4. Генераторы
### - фильтрация транзакций по валюте;
### - поочерёдное получение описаний операций;
### - генерация номеров банковских карт в заданном диапазоне.
## 5. Декоратор
### - отслеживание вызова функций;
### - обрабатывать ошибки;
### - возможность записи в файл;

#  🧩 Использование:
### - безопасного отображения платёжных реквизитов;
### - форматирования дат;
### - фильтрации списка операций по статусу и валюте;
### - упорядочивания операций по дате;
### - получение описания операций;
### - логировать вызовы функций и ошибки;
### - выводит данные в консоль или файл.

## 📦 Установка и запуск

Для работы проекта требуется Python **3.14+** и Poetry.

### 1. Установите Poetry (если ещё не установлен)
```pip install poetry```
### 2. Клонирование репозитория
### `git clone git@github.com:vadimsemenov53-crypto/Homework_Bank_SkyPro.git`
### 3. Установка зависимостей
### ```poetry install```
### 4. Запуск тестов
### ```pytest```
#### Проверка покрытия кода:
```pytest --cov=src --cov-report=term-missing```
