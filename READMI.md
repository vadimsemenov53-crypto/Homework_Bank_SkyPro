# Виджет банковских операций клиента

## Простой виджет на Python для обработки и отображения данных о банковских операциях.

# Основные функции:
## 1. Маскировка платёжных данных
## 2. Обработка даты и времени
## 3. Фильтрация по статусу операции
## 4. Сортировка по дате

# Использование:
### - безопасного отображения платёжных реквизитов;

### - форматирования дат;

### - фильтрации списка операций по статусу;

### - упорядочивания операций по дате.

## Установка и запуск

Для работы проекта требуется Python **3.14+** и Poetry.

### 1. Установите Poetry (если ещё не установлен)
```pip install poetry```
### 2. Клонирование репозитория
### `git clone git@github.com:vadimsemenov53-crypto/Homework_Bank_SkyPro.git`
### 3. Запустите тестовый вариант проекта
### ```python test/test_main.py```

# Примеры работы виджета:
```
# Маскировка номера карты
print(get_mask_card_number("1234567812345678"))
# → 1234 56** **** 5678

print(get_mask_card_number("123"))
# → Номер карты должен содержать 16 цифр

# Маскировка номера счета
print(get_mask_account("40817810099910004312"))
# → **4312

# Автоматическая маскировка карты или счёта
print(mask_account_card("Счет 40817810099910004312"))
# → Счет **4312

print(mask_account_card("Visa Platinum 1234567812345678"))
# → Visa Platinum 1234 56** **** 5678

# Преобразование даты
print(get_date("2024-03-11T02:26:18.671407"))
# → 11.03.2024
```
